# Crit 7 reflection

## What was the breakthrough that moved the work forward?

The breakthrough that moved the work forward was thinking about which ANU
system I am genuinely frustrated with rather than trying to invent a problem.
The enrolment process stood out immediately. To enrol in a course, I currently
have to find the course through the ANU Programs and Courses website, open the
course, navigate to the Class tab, find the relevant class number, and then
enter that number into the separate ANU Hub system. I found that this involved
several unnecessary steps for a relatively simple task.

## What did this work change about who I want to be as a software developer?

I want to build software that reduces unnecessary friction. This meant paying
attention not only to whether my application technically worked, but also to
whether the interaction made sense from the user's perspective. I want to
carry this mindset into future projects: question unnecessary steps, test the
actual experience, and design around what the user is trying to accomplish
rather than around how an existing system happens to be structured.
